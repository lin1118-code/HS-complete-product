# Cosmetic HS Classification Starter

## 현재 단계
- 사례집 기반 데이터 로딩 및 점검
- 다국어 입력 필드 결합
- 중복 입력을 같은 CV 그룹으로 묶기
- 희소 클래스 문제를 고려한 Dummy baseline 평가

## 데이터
원본 Excel은 저장소에 포함하지 않습니다. Google Colab에서 업로드해 사용하세요.
필요한 시트 이름은 `사례_전처리 완료`입니다.

## 실행
1. `notebooks/01_baseline.ipynb`를 Google Colab에서 엽니다.
2. Excel 파일을 업로드합니다.
3. 셀을 순서대로 실행합니다.

## 평가 설계 주의
현재 데이터는 177건, 31개 HS 코드로 구성되어 있습니다. 모든 클래스를 5-Fold로 안정적으로 평가하기 어렵기 때문에, 첫 기준 실험에서는 사례 수가 5건 이상이고 서로 다른 입력 그룹이 4개 이상인 클래스를 대상으로 4-Fold StratifiedGroupKFold를 사용합니다. 희소 클래스는 제거하는 것이 아니라 별도 분석 대상으로 보존합니다.

동일 입력 사례는 같은 Fold에 배치하여 중복 입력으로 인한 데이터 누수를 방지합니다.

## HS 해설서 통합 검색 실험
- `19_explanatory_note_integration.ipynb`: 기존 최종 모델 평가 조건을 유지하면서 HS 해설서 지식베이스 검색과 과거 판정 사례 검색을 RRF로 결합하는 실험입니다.
- 실행 환경: Google Colab 또는 Python 3 환경에서 노트북 셀을 순서대로 실행합니다.
- 결과물: OOF 예측, 모델 성능 비교, Fold별 지표, 클래스별 지표, 해설서 검색 근거를 CSV로 저장합니다.
- 본 실험은 검색 기반 HS 코드 후보 추천이며 법적 분류의 자동 확정이 아닙니다.
